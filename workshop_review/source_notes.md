## Advisory mode

[Claude advisor](https://code.claude.com/docs/en/advisor) describes experimental `/advisor`. It is distinct from Plan Mode, depends on provider/billing, and may consume additional tokens or credits. The workshop mentions it as an optional feature and makes no recommendation to consume scarce allowance or any inference of model superiority.

## VS Code: local external sessions

[Manage sessions](https://code.visualstudio.com/docs/agents/run/sessions/manage-sessions) documents discovery of local external Claude Code and Codex sessions. They are hidden by default and can be shown with the External filter or `chat.agentSessions.showExternal`. Codex continuation requires a single writer: fully quit the other application, then use Retry. This does not establish arbitrary remote SSH/tmux discovery.

[Agent harnesses](https://code.visualstudio.com/docs/agents/run/agent-harnesses) distinguishes the OpenAI extension, which uses the editor Chat view, from experimental Codex Agent Host support for the Agents window. The documented settings include `chat.agentHost.codexAgent.enabled` and `chat.editor.codex.preferAgentHost`; enterprise policy can disable providers. These settings are reference notes rather than mandatory classroom setup. A Claude model selected inside Copilot still runs in the Copilot harness.
