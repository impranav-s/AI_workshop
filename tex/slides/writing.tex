\begin{frame}{AI-Assisted Writing Starts with the Argument}
\begin{enumerate}\setlength{\itemsep}{0.2cm}
\item \textbf{Claims:} What do we know, and what evidence supports it?
\item \textbf{Interpretation:} What economic mechanism does the evidence establish?
\item \textbf{Exhibits:} Specify the figure or table that lets a reader assess the claim.
\item \textbf{Prose:} Write the paragraph around the verified evidence.
\end{enumerate}
\par\vspace{0.2cm}
\begin{block}{A useful first request}
Read the approved results and the surrounding section. List the claims each exhibit supports, the qualifications it needs, and any missing evidence. Then propose the paragraph's argument.
\end{block}
\small Keep missing results explicit. A fluent paragraph cannot supply an estimate, citation, or identification argument.
\end{frame}

\begin{frame}{Author Instructions: Write for the Paper's Reader}
\begin{columns}[t]
\begin{column}{0.56\textwidth}
\begin{itemize}\setlength{\itemsep}{0.15cm}
\item Use established terms; do not coin labels.
\item Remove stock trailing clauses and contrastive padding.
\item State the economic argument directly.
\item Keep chat history and internal workflow out of the manuscript.
\item Introduce notation only when necessary; define every new symbol.
\end{itemize}
\end{column}

\begin{frame}{A Synthetic Paragraph: Give the Agent the Claims}
\small
\textbf{Approved content:} Students pay an application cost before the offer is known. The expected value of enrollment and continuation enters their application decision. No estimated magnitude is available.
\par\vspace{0.15cm}
\begin{block}{Before: plausible wording, poor direction}
Our forward-looking access-persistence nexus leverages a dynamic framework, underscoring the pivotal role of expectations. This is not merely about admission but about sustained success. After resolving the implementation issues, we can now show substantial gains.
\end{block}
\begin{block}{Author-directed revision}
Students pay an application cost before learning whether they receive an offer. Their application decision depends on the expected value of enrolling and continuing in the program.
\end{block}
\textbf{Direction:} Use only the approved content. Keep the timing and mechanism. Remove coined labels, workflow history, and unsupported results. Introduce no notation.
\par\vfill
\sources{Synthetic teaching example written for this workshop; no empirical finding or selected research-demo model is implied.}
\end{frame}

\begin{frame}{The Author Still Reviews the Writing}
\begin{itemize}\setlength{\itemsep}{0.25cm}
\item Read the passage as someone who has only the paper.
\item Check every claim against the source, exhibit, and intended interpretation.
\item Check whether the edit changes the argument or adds a new qualification.
\item Recheck the author rules: a model can drift back to default phrasing.
\end{itemize}
\par\vspace{0.25cm}

Tomas's preference for OpenAI models for some writing tasks reflects his experience. Better coding performance does not establish better research writing.
\end{block}

\end{frame}
